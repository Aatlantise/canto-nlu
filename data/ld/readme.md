# Language detection

This is the language detection (LD) subset of CantoNLU: a 3-way
classification task distinguishing Cantonese, Mandarin, and code-mixed/corrupted
sentences, built from `HKAllen/cantonese-chinese-parallel-corpus`.

## Dataset info
For each Cantonese/Mandarin sentence pair in the source corpus, word
alignments are computed with `simalign`, and up to 6 corrupted variants are
generated by randomly swapping aligned words between the Cantonese and
Mandarin sides at three corruption rates (15%/33%/50%, in each direction).
Each example is a single sentence with a 3-way label:
* `0`: original Cantonese sentence
* `1`: original Mandarin sentence (converted to traditional characters)
* `2`: corrupted, partially code-mixed sentence

`source_id` links sentence variants derived from the same source pair.
```json
{"id": 0, "source_id": 0, "sentence": "建生邨屬於租者置其屋計劃的屋邨，同一大廈內，有些單位已經賣咗，其餘嘅係租住單位。", "label": 2}
```

## Requirements
Run `python3 convert_ld.py [--n-sentences 10000] [--device mps|cpu]`.
The script downloads `HKAllen/cantonese-chinese-parallel-corpus` via
`datasets.load_dataset` and requires `torch`, `datasets`, `hanziconv`,
`simalign`, `tqdm`, and `transformers`.

## Artifacts
`ld_train.jsonl`, `ld_val.jsonl`, `ld_test.jsonl` (split 90/5/5 by `source_id`,
so variants of the same source pair stay in the same split).

`sample_ld.py` extracts a class-balanced sample (`ld_sample.csv`, 101 rows)
from `ld_test.jsonl` for spot-checking/human annotation.
