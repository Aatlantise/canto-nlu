# Part-of-speech tagging (POS)

This folder contains zero-shot evaluators for Qwen, Gemma, Llama, and DeepSeek, plus supervised mBERT/XLM-R fine-tuning. `qwen_pos_eval.py` provides shared parsing and metrics used by the local-model wrappers.

`POS_HELDOUT_TEST_RUN.md` documents held-out evaluation, while the model-specific run guides preserve earlier execution notes. Dataset JSONL files are intentionally excluded.
