# Linguistic acceptability judgment (LAJ)

The LAJ task uses forced-choice sentence pairs. `eval_mlm_laj.py` scores masked language models with pseudo-surprisal. `eval_causal_laj.py` and `eval_qwen_laj.py` score causal language models with sentence surprisal.

`LAJ_EVALUATION.md` and `LAJ_MBERT_XLMR_LLAMA_RUN.md` describe the evaluation conventions. Source sentence and comparison-pair datasets are intentionally excluded.
