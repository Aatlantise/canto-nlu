# Natural language inference (NLI)

`nli_encoder_finetune.py` covers mBERT and XLM-R supervised runs. `nli_prompted_eval.py` covers local instruction models, and `nli_deepseek_eval_stdlib.py` covers the DeepSeek API. `summarize_nli_results.py` assembles result tables.

See `NLI_ALL_MODELS_README.md` for the six-model protocol. The balanced evaluation sample and full dataset are intentionally excluded from this public-code staging area.
